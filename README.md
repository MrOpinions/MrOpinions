### 🚀 Featured Projects

#### 🔐 QDS Sentinel
*Frontend developer & technical researcher* · [Repo](https://github.com/rayhaanshah32-svg/QDS-sentinal)

A research-grade prototype that detects cyber threats (forgery, replay, impersonation, channel manipulation) in teleportation-based **Quantum Digital Signature** systems, using deterministic, statistical monitoring instead of ML.
- Built the dashboard that renders real-time security metrics
- Researched information-theoretic security principles to tune the detection thresholds

#### ❤️ BME Ignite Hackfest 2026: Wearable Vitals Monitor
*24-hour biomedical hackathon at REC*

An ESP32 + MAX30100 wearable that streams heart rate and SpO₂ to an app and server, where a quantum-inspired ML model learns from each day's data and alerts the doctor on anomalies.
- Three roles: patient, doctor, and lab technician (lab reports visible to both patient and doctor)
- MongoDB-backed web portal for records

#### 🦯 Predictive Smart Walking Stick
*Hacktivate 2026 · assistive-tech challenge*

An ESP32 + HC-SR04 ultrasonic walking stick that warns users about obstacles, with a predictive layer on top of plain distance sensing.

#### 👂 SoundMind
*SmartAbility 2026 Innovation Challenge (REC x NIEPMD)*

A software-only, AI-based tinnitus assessment and rehabilitation system.

#### ☢️ Nuclear Plant Management Dashboard
*Group hackathon project*

A dark, neon-styled monitoring dashboard with reactor panels and animated PWR diagrams.
